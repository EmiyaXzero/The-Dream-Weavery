# 质量检查清单参考

> 本文档为 writing-agent 和 coordinator-agent 提供质量检查清单参考。加载后，按照本文档的清单进行检查。

## 一、章节发布前检查

- [ ] 时间线是否与前后章节一致
- [ ] 人物行为是否符合性格
- [ ] 修炼进度/能力提升是否合理
- [ ] 派系关系是否正确
- [ ] 是否有爽点（至少1个）
- [ ] 结尾是否有钩子（悬念型/期待型/反差型）
- [ ] 标题是否包含看点/爽点/情绪
- [ ] 技术描写是否简洁真实
- [ ] 格式是否规范（无单独成行的"——"）
- [ ] 场景切换是否规范（空行/时间词/地点词/视角切换）
- [ ] 每章是否只干了一件事（一章一事原则）
- [ ] 段落是否太长（超过5行）？
- [ ] 对话是否简洁有力？

## 二、卷末检查

- [ ] 卷末成果是否达成
- [ ] 主要伏笔是否回收
- [ ] 人物成长是否完成
- [ ] 是否引出下一卷主线
- [ ] 节奏曲线是否完整（铺垫→小高潮→过渡→上升→大高潮）
- [ ] 爽点密度是否达标（根据平台要求）
- [ ] 逻辑是否自洽（时间线/人物行为/修炼进度/派系关系）

## 三、逻辑检查清单

### 3.1 时间线一致性

- [ ] 章节之间的时间跨度是否合理
- [ ] 时间词（三天后/第二天等）是否一致
- [ ] 时间线是否混乱（第8章完成大项目，第9章又回到早期事件）

### 3.2 章节衔接检查

- [ ] 上章钩子与本章开头是否衔接
- [ ] 本章结尾钩子与下章开头是否衔接
- [ ] 是否有断裂/跳跃

### 3.3 人物行为逻辑

- [ ] 人物行为是否符合性格
- [ ] 人物行为是否符合立场和利益
- [ ] 人物行为是否OOC（Out Of Character）

### 3.4 修炼进度/能力提升合理性

- [ ] 修炼进度是否符合力量体系的设定
- [ ] 能力提升是否太快/太慢
- [ ] 装备/资源获取是否合理

### 3.5 派系关系一致性

- [ ] 派系关系是否符合设定
- [ ] 派系关系变化是否有合理动机
- [ ] 派系行为是否符合利益

## 四、常见错误检查清单

### 4.1 节奏太慢

- [ ] 第1章是否进入了危机/冲突？
- [ ] 金手指是否在1-2章亮相？
- [ ] 是否有大段环境描写/主角日常？

### 4.2 爽点不突出

- [ ] 标题是否包含看点/爽点/情绪？
- [ ] 爽点是否藏住了（必须写在标题里）？
- [ ] 每章是否有至少1个爽点？

### 4.3 一章多线

- [ ] 每章是否只干了一件事（一章一事原则）？
- [ ] 是否有章节写了战斗+感情+升级+寻宝？

### 4.4 逻辑混乱

- [ ] 时间线是否混乱？
- [ ] 人物地位是否忽高忽低？
- [ ] 势力规模是否前后矛盾？

### 4.5 技术/能力描写太复杂

- [ ] 是否有大段贴代码/技能说明？
- [ ] 是否有太多专业术语，没有解释？
- [ ] 技术描写是否简洁真实？

### 4.6 格式不规范

- [ ] 是否有单独成行的"——"？
- [ ] 场景切换是否规范？
- [ ] 是否有大段环境描写/内心独白？

## 五、平台适配检查清单

### 5.1 番茄小说

- [ ] 节奏是否极快（开局即高潮）？
- [ ] 爽点密度是否极高（每章至少1个爽点）？
- [ ] 风格是否轻松爽文，不要太虐？
- [ ] 章节字数是否在2000-2500字之间？

### 5.2 七猫小说

- [ ] 节奏是否快（开局要有 hook）？
- [ ] 爽点密度是否高（每章1个爽点）？
- [ ] 风格是否轻松爽文/甜宠？
- [ ] 章节字数是否在2000-3000字之间？

### 5.3 起点中文网

- [ ] 节奏是否可慢热（前期铺垫OK）？
- [ ] 爽点密度是否中（每3章1个爽点）？
- [ ] 风格是否深度剧情，逻辑要硬？
- [ ] 章节字数是否在3000-3500字之间？

### 5.4 晋江文学城

- [ ] 节奏是否可慢热（注重感情线）？
- [ ] 爽点密度是否中（感情线为主）？
- [ ] 风格是否甜宠/虐恋/BE美学？
- [ ] 章节字数是否在2000-3000字之间？

## 六、使用说明

1. **加载本模板后**，按照「章节发布前检查」清单，每章发布前检查
2. **卷末时**，按照「卷末检查」清单，进行卷末检查
3. **逻辑检查时**，按照「逻辑检查清单」，逐项检查
4. **常见错误检查时**，按照「常见错误检查清单」，逐项检查
5. **平台适配时**，按照「平台适配检查清单」，根据平台选择对应清单检查

## 七、质量评估维度

### 7.1 节奏感

- 是否符合目标平台的节奏要求？
- 黄金三章是否设计到位？
- 每章是否留了钩子？

### 7.2 爽点密度

- 是否达到目标平台的爽点分布要求？
- 爽点类型是否多样（不要只有一种爽点）？
- 爽点是否突出（标题包含爽点关键词）？

### 7.3 审核合规

- 是否触发审核红线？
- 是否有敏感词/敏感内容？

### 7.4 文笔质量

- 是否符合目标风格（轻松爽文/深沉史诗/甜宠言情）？
- 对话是否简洁有力？
- 段落是否太长？

### 7.5 逻辑一致性

- 时间线是否一致？
- 人物行为是否符合性格？
- 修炼进度是否合理？
- 派系关系是否一致？
