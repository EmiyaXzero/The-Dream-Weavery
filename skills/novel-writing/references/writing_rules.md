# 正文创作规则参考

> 本文档为 writing-agent 提供正文创作的核心规则参考。加载后，按照本文档的规则进行正文创作。

## 一、黄金节奏公式

```
开局炸 → 金手指快 → 冲突密 → 每章留钩子
```

## 二、三秒法则

读者在3秒内决定是否继续看：
- 第1章必须进入危机/冲突
- 金手指必须在第1-2章亮相
- 标题必须包含看点/爽点/情绪

## 三、一章一事原则

- 每章只干一件事
- 结尾必须留钩子
- 不要一章写5件事

## 四、标题设计公式

```
[情绪/动作/结果] + [爽点关键词]
```

示例：
- 穿越2087！智械屠城，我在绝境醒来
- 这群人，连手写代码都不会？
- 上古编程术：一行汇编重启地心核心

## 五、钩子设计三种方式

1. **悬念型**：「就在这时，意外发生了...」
2. **期待型**：「接下来，他要挑战的是...」
3. **反差型**：「但所有人都没想到...」

## 六、爽点不能藏

- 必须写在标题里
- 古法编程、汇编、C语言、手写代码
- 技术碾压、打脸、震惊、觉醒

## 七、章节结构模板

```
开头（10%）：
  - 承接上章结尾的钩子
  - 快速进入剧情（不要大段环境描写）
  - 1-2句话承接即可

发展（60%）：
  - 核心事件展开（一章一事）
  - 多视角叙事（主角视角70% + 配角视角20% + 反派视角10%）
  - 技术细节描写（简洁、真实、用比喻让非专业读者理解）
  - 对话推动剧情（不要大段旁白）

高潮（20%）：
  - 爽点爆发（技术碾压/打脸/反转）
  - 金句频出（符合人物性格和处境）
  - 情绪推向最高点

结尾（10%）：
  - 留下钩子（悬念型/期待型/反差型）
  - 引出下一章（不要完全解决问题）
  - 1-3句话收尾即可
```

## 八、黄金三章设计（前3章特别重要）

```
第1章：
  - 开局炸：直接进入危机/冲突
  - 金手指亮相：1-2章内必须亮相
  - 标题：必须包含看点/爽点/情绪
  - 结尾钩子：强悬念，让读者忍不住看第2章

第2章：
  - 展开金手指：详细展示金手指的能力/用法
  - 第一个小冲突：展示金手指的威力
  - 结尾钩子：期待型，铺垫第3章的打脸

第3章：
  - 第一个小高潮：打脸/技术碾压/反转
  - 收获：获得第一个小成果（资源/认可/势力）
  - 结尾钩子：引出下一个小目标
```

## 九、多视角叙事规范

```
主角视角（70%）：
  - 推进主线剧情
  - 展示主角成长
  - 爽点爆发

配角视角（20%）：
  - 展示世界观其他部分
  - 衬托主角
  - 推动剧情

反派视角（10%）：
  - 展示反派阴谋
  - 增加压迫感
  - 铺垫最终决战
```

## 十、金句设计

- 每20-50章至少1句金句
- 金句要符合人物性格和处境
- 金句要有代表性，体现核心价值观
- 金句要简洁有力，不要太长

## 十一、使用说明

1. **加载本模板后**，严格按照「黄金节奏公式」创作
2. **第1章**必须炸，严格按照「黄金三章设计」
3. **每章**必须留钩子，严格按照「钩子设计三种方式」
4. **标题**必须按照「标题设计公式」设计
5. **章节结构**严格按照「章节结构模板」
6. **多视角叙事**严格按照「多视角叙事规范」
7. **金句**按照「金句设计」规范设计
