# 格式规范参考

> 本文档为 writing-agent 提供格式规范参考。加载后，按照本文档的规范进行格式检查。

## 一、禁止分隔符（重要！）

**禁止使用"——"（破折号）作为场景分隔符！**

❌ 错误用法：
```
王小二转身离开。

——

三天后，镜之城。
```

✅ 正确用法：
```
王小二转身离开。


三天后，镜之城。
```

## 二、场景切换方式

**场景切换4种方式**：

1. **空行分隔**：两个段落之间空一行
2. **时间词开头**：「三天后」「第二天清晨」「当晚」
3. **地点词开头**：「镜之城」「休整区角落」
4. **人物视角切换**：「与此同时，乔瑜……」

## 三、例外情况

**破折号可以用于**：

- 对话中的打断：「你——」
- 语气停顿：「她想说些什么——但最终没有说出口」
- 解释说明：「筛选者——那些被选中的人」

## 四、检查标准

**单独成行的"——"必须为0处。**

检查方法：
```
1. 搜索正文中的"——"
2. 检查是否是例外情况（对话打断/语气停顿/解释说明）
3. 如果是单独成行的"——"，必须修改为4种场景切换方式之一
```

## 五、段落规范

```
- 段落不要太长（3-5行为宜）
- 对话要简洁有力
- 不要大段环境描写
- 不要大段内心独白
- 用对话/动作推进剧情
```

## 六、对话规范

```
- 对话要简洁有力，不要拖沓
- 对话要符合人物性格
- 对话要推动剧情，不要无意义闲聊
- 对话标签要简洁（「他说」「她问」即可，不要「他深情地说道」）
```

## 七、章节字数规范

| 平台 | 章节字数 | 说明 |
|------|----------|------|
| 番茄小说 | 2000-2500字 | 节奏快，字数可以稍少 |
| 七猫小说 | 2000-3000字 | 节奏快，字数可以稍少 |
| 起点中文网 | 3000-3500字 | 可以慢热，字数可以稍多 |
| 晋江文学城 | 2000-3000字 | 感情线为主，字数适中 |

**特殊章节字数**：
- 技术章节：2500字左右
- 战斗章节：3000-3500字
- 感情章节：2000-2500字

## 八、使用说明

1. **加载本模板后**，严格按照「场景切换4种方式」进行场景切换
2. **禁止使用"——"作为场景分隔符**，例外情况除外
3. **检查标准**：单独成行的"——"必须为0处
4. **段落规范**：段落不要太长（3-5行为宜）
5. **对话规范**：对话要简洁有力，符合人物性格
6. **章节字数**：根据平台调整章节字数
