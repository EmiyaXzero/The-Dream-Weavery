# 节奏曲线模板参考

> 本文档为 outline-agent 提供各题材、各平台的节奏曲线设计参考。加载后，按照本文档的模板规划节奏。

## 一、通用节奏曲线模板

### 1.1 每卷节奏曲线

```
每卷节奏（8卷×50章模式）：
  铺垫（第1-5章）→ 小高潮（第6-15章）→ 过渡（第16-25章）→ 上升（第26-35章）→ 大高潮（第36-50章）

每章节奏：
  开头（10%）：承接上章钩子，快速进入剧情
  发展（60%）：核心事件展开，多视角叙事
  高潮（20%）：爽点爆发
  结尾（10%）：留钩子，引出下一章
```

### 1.2 全书节奏曲线

```
全书节奏（400章模式）：
  第1-3章：黄金三章，必须炸（开局危机+金手指亮相+第一个小高潮）
  第4-50章（第一卷）：快速上升，每章有爽点
  第51-100章（第二卷）：势力萌芽，爽点密度稍降，伏笔埋设
  第101-150章（第三卷）：中期高潮，爽点密度再提升
  第151-200章（第四卷）：受挫/顿悟，节奏稍缓，为最终卷蓄力
  第201-250章（第五卷）：最终备战，爽点密度极高
  第251-300章（第六卷）：最终决战开始，高潮迭起
  第301-350章（第七卷）：最终决战，全书最高潮
  第351-400章（第八卷）：尾声，交代后续，留有余味
```

## 二、分平台节奏模板

### 2.1 番茄小说节奏模板（极快节奏）

```
特点：开局即高潮，爽点极密，不要任何冗余描写

第1章：直接进入危机/冲突，金手指亮相
第2章：展开金手指，第一个小冲突
第3章：第一个小高潮（打脸/技术碾压）

每章结构：
  开头（5%）：承接上章钩子（1-2句话）
  发展（50%）：核心事件展开，快速推进
  高潮（35%）：爽点爆发（必须每章至少1个爽点）
  结尾（10%）：强钩子（必须让读者忍不住看下一章）

爽点密度：
  技术碾压/打脸：每1-2章一次
  小高潮：每10章一次
  大高潮：每50章一次
```

### 2.2 七猫小说节奏模板（快节奏）

```
特点：开局要有hook，爽点密集，风格轻松

第1章：强hook开场（危机/冲突/悬念）
第2-3章：金手指亮相+第一个小高潮

每章结构：
  开头（10%）：承接上章钩子
  发展（55%）：核心事件展开
  高潮（25%）：爽点爆发
  结尾（10%）：钩子（期待型/悬念型）

爽点密度：
  爽点：每章至少1个
  小高潮：每15章一次
  大高潮：每50章一次
```

### 2.3 起点中文网节奏模板（可慢热）

```
特点：可以慢热，前期铺垫OK，但要有深度，逻辑要硬

第1-3章：铺垫世界观/主角处境，金手指可稍晚亮相（但不超过5章）
第4-10章：展开金手指，第一个小冲突
第11-20章：第一个小高潮

每章结构：
  开头（10%）：承接上章
  发展（60%）：核心事件展开，可有多条线索
  高潮（20%）：爽点爆发/剧情推进
  结尾（10%）：钩子（可弱可强，关键是剧情有深度）

爽点密度：
  爽点：每3章1个
  小高潮：每20章一次
  大高潮：每50-100章一次

注意：起点读者更喜欢深度剧情和复杂的人物关系，不要为了爽而爽
```

### 2.4 晋江文学城节奏模板（感情线为主）

```
特点：可以慢热，感情线为主，爽点密度中等

第1-3章：铺垫主角处境/感情线初现
第4-10章：感情线发展，金手指可稍晚亮相
第11-20章：感情线小高潮（暧昧/误会/和好）

每章结构：
  开头（10%）：承接上章
  发展（60%）：剧情推进+感情线发展
  高潮（20%）：感情高潮/剧情高潮
  结尾（10%）：钩子（感情钩子/剧情钩子）

爽点密度：
  感情爽点（甜/虐）：每章至少1个
  剧情爽点：每5章1个
  大高潮：每50-100章一次

注意：晋江读者更喜欢感情线，剧情是其次，甜宠/虐恋/BE美学要根据题材选择
```

## 三、分题材节奏模板

### 3.1 仙侠/修仙节奏模板

```
特点：升级流，爽点在升级和打脸

卷级节奏：
  第一卷（练气-筑基）：入门，被打压→逆袭
  第二卷（筑基-金丹）：小有名气，宗门大比
  第三卷（金丹-元婴）：崭露头角，宗门战争
  第四卷（元婴-化神）：一方霸主，大能争锋
  第五卷（化神-炼虚）：飞升在即，两界大战
  第六卷（炼虚-合道）：仙界篇，仙界争霸
  第七卷（合道-大乘）：仙界巅峰，准备飞升
  第八卷（大乘-飞升）：终极决战，飞升成仙

爽点设计：
  升级：每卷至少1次大升级
  打脸：每5-10章一次（被打压→打脸）
  寻宝/秘境：每卷1-2次
  收徒/收小弟：每卷1次
```

### 3.2 都市节奏模板

```
特点：商战/娱乐圈/医武，爽点在打脸和成功

卷级节奏：
  第一卷：主角出场，被打压→初步逆袭
  第二卷：小有名气，第一个小目标达成
  第三卷：崭露头角，与反派第一次正面交锋
  第四卷：受挫/顿悟，实力/势力上台阶
  第五卷：中期高潮，解决中期主线
  第六卷：新的危机，面对更强大的敌人
  第七卷：最终备战，集结力量
  第八卷：最终决战，成为行业顶尖

爽点设计：
  打脸：每5-8章一次
  成功（商业/比赛/医案）：每10章一次
  暧昧/感情：每20章一次小进展
  装逼：每3-5章一次
```

### 3.3 末世节奏模板

```
特点：生存压力，爽点在技术碾压和势力扩张

卷级节奏：
  第一卷：末世降临，主角觉醒/重生，建立初期生存点
  第二卷：势力萌芽，收服第一批追随者
  第三卷：资源争夺，与敌对势力第一次大战
  第四卷：受挫/顿悟，技术/异能突破
  第五卷：中期高潮，统一地下城/区域
  第六卷：新的威胁（更高级丧尸/智械/异族）
  第七卷：最终备战，集结所有力量
  第八卷：最终决战，解决最终威胁，建立新秩序

爽点设计：
  技术碾压（技术流）：每3-5章一次
  战斗爽点：每5-8章一次
  收服/建立势力：每卷1-2次
  装备/资源获取：每10章一次
```

## 四、使用说明

1. **选择平台模板**：根据目标平台，选择 2.1-2.4 中的对应模板
2. **选择题材模板**：根据题材类型，选择 3.1-3.3 中的对应模板（如有）
3. **结合使用**：平台模板决定节奏快慢，题材模板决定爽点类型
4. **调整节奏**：根据预估长度调整（短篇加快，长篇可稍慢）
5. **规划卷级节奏**：参考 1.1 的每卷节奏曲线，规划每一卷
6. **规划章节节奏**：参考 1.1 的每章节奏，规划每一章

## 五、质量检查

- [ ] 节奏是否符合目标平台要求？
- [ ] 爽点密度是否达标？
- [ ] 每章是否都留了钩子？
- [ ] 黄金三章是否够炸？
- [ ] 卷末是否是阶段性成果/大高潮？
- [ ] 全书节奏曲线是否完整（铺垫→高潮→过渡→上升→大高潮）？
