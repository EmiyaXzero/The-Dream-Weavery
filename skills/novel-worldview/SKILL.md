# Novel Worldview Skill

触发 worldview-agent 进行世界观设定构建。支持按题材加载参考模板，生成结构化、可扩展的世界观文档。

## 触发词

世界观、世界设定、力量体系、等级体系、地图、地理、历史、势力、派系、金手指、修炼体系、仙侠、修仙、都市、商战、科幻、星际、历史、穿越、末世、废土、无限流、副本、游戏、电竞、悬疑、推理

## 行为

1. 加载 `agents/worldview-agent.md`
2. 根据题材类型加载 `skills/novel-worldview/references/genre_<类型>.md` 参考模板
3. 根据输入需求（题材、风格、长度、平台、特殊要求）设计世界观
4. 输出完整世界观设定文档（结构化JSON + 可读Markdown）
5. 触发下一环节（角色设计）

## 输出文件

- `.codebuddy/workspace/world_setting.json` — 结构化世界观设定
- `.codebuddy/workspace/world_setting.md` — 人类可读的世界观文档

## 题材参考模板

| 题材 | 参考文件 | 核心要素 |
|------|----------|----------|
| 仙侠/修仙 | `references/genre_immortal.md` | 修炼体系、仙界架构、法宝体系、宗门势力 |
| 都市 | `references/genre_modern.md` | 商业体系、社会阶层、特殊能力、隐秘组织 |
| 科幻 | `references/genre_scifi.md` | 科技树、星际政治、外星种族、AI意识 |
| 历史 | `references/genre_history.md` | 朝代体系、军事制度、文化礼仪、官场架构 |
| 末世 | `references/genre_apocalypse.md` | 废土势力、生存资源、变异体系、智械危机 |
| 无限流 | `references/genre_unlimited.md` | 副本世界、主神空间、轮回规则、跨世界能力 |
| 游戏 | `references/genre_game.md` | 游戏系统、职业体系、副本机制、装备掉落 |
| 悬疑 | `references/genre_mystery.md` | 犯罪体系、侦查手段、心理分析、真相反转 |

## 质量标准

生成的 worldview 必须包含：

1. **力量/修炼体系**：明确的等级划分、多路线设计、升级方式
2. **金手指设定**：核心+隐藏+成长型三部分
3. **势力设计**：至少3个主要势力+2个隐藏势力
4. **权力架构**：层级划分+博弈设计
5. **独特亮点**：至少3个，避免套路化
6. **逻辑一致性**：修炼进度合理、派系关系一致、时间线一致

## 注意事项

- 必须按照题材加载对应的参考模板，不跨题材混用元素
- 金手指必须有成长性，不能开局满级
- 隐藏势力必须有铺垫和揭晓节点
- 输出完成后，明确触发下一环节（角色设计）
