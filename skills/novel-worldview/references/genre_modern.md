# 都市题材 — 世界观参考模板

> 本文档为 worldview-agent 提供都市题材的世界观设计参考。加载后，按照本文档的框架生成世界观设定。

## 一、世界观框架参考

### 1.1 核心赛道公式
```
都市 + <核心冲突> + <势力博弈> + <特殊元素> + <能力体系> + <商战/权谋>
```

示例：
- `都市 + 商业争霸 + 财团博弈 + 系统金手指 + 商战能力 + 建立商业帝国`
- `都市 + 隐秘世界 + 超凡组织 + 特殊能力 + 多能力路线 + 守护普通人`
- `都市 + 娱乐圈 + 资本博弈 + 文娱系统 + 创作能力 + 文化输出`

### 1.2 独特亮点参考（至少选择3个）

- **系统金手指**：主角携带系统，可以兑换技能/物品/信息
- **隐秘世界**：普通人不知道的隐秘世界（修仙者/异能者/妖怪混居在都市中）
- **商业帝国**：主角从零开始，建立横跨多领域的商业帝国
- **娱乐圈**：主角进入娱乐圈，成为顶流/导演/编剧
- **医武双修**：主角精通医术和武学，悬壶济世+武力护身
- **学霸逆袭**：主角智商超群，从学渣变学霸，改变命运
- **重生商战**：主角带着前世记忆重生，已知未来商业大势
- **豪门恩怨**：主角本是豪门子弟，被陷害后逆袭回归
- **特种兵王**：主角曾是特种兵王，回归都市保护雇主/复仇
- **隐世家族**：都市中隐藏着古老的武术/修仙家族，掌控地下世界

## 二、能力体系参考

### 2.1 商业/文娱能力体系（无超凡元素）

| 等级 | 名称 | 描述 |
|------|------|------|
| 1 | 入门级 | 掌握基础技能（编程/金融/创作等） |
| 2 | 熟练级 | 在某一领域有小成 |
| 3 | 进阶级 | 在某一领域有影响力 |
| 4 | 专家级 | 行业专家，有话语权 |
| 5 | 大师级 | 行业顶尖，制定规则 |
| 6 | 传奇级 | 跨领域影响力，改变行业 |

### 2.2 超凡能力体系（有超凡元素）

| 路线名称 | 描述 | 兼容路线 |
|----------|------|----------|
| 武修 | 古武术修炼，强身健体+战斗 | 医修 |
| 医修 | 中医/西医，治病救人 | 武修 |
| 异能 | 觉醒特殊能力（精神/元素/预言等） | 武修 |
| 修仙 | 隐藏在都市中的修仙者 | 异能 |
| 系统 | 系统赋予的能力 | 所有路线 |

## 三、势力设计参考

### 3.1 商业势力框架

```
顶级财团（3-5个）：
- 掌控国家经济命脉
- 有政治影响力
- 涉及多个行业

一流企业（10-20个）：
- 行业龙头
- 附庸于顶级财团或独立

二流企业（数百个）：
- 中型企业
- 在某一领域有竞争力

初创企业/主角势力：
- 从零开始
- 逐渐成长，挑战既有秩序
```

### 3.2 隐秘势力框架（有超凡元素）

```
正派：
- 隐世修仙家族（守护者）
- 异能者协会（管理者）
- 特殊事务局（官方）

反派：
- 黑暗议会（反派大本营）
- 邪恶组织（进行非法实验）
- 外国势力（图谋本土超凡资源）

中立：
- 杀手组织（拿钱办事）
- 情报贩子（贩卖信息）
- 地下交易所（超凡资源交易）
```

## 四、金手指设计参考

### 4.1 核心金手指

- **商业/文娱系统**：可以兑换未来信息/技能/物品
- **万能APP**：手机上的一个神秘APP，可以搞定一切
- **医术/武学传承**：获得上古医道/武道传承
- **超级大脑**：智商突破天际，过目不忘、计算力惊人
- **透视/读心**：特殊能力，看穿一切/读取心声

### 4.2 隐藏金手指

- **双重身份**：主角表面上是普通人，实则隐藏身份（第50章揭晓）
- **前世记忆**：主角前世是某个大人物，重生归来（第80章揭晓）
- **神秘师父**：主角有一个神秘师父，关键时刻出手（第100章揭晓身份）

## 五、地理与历史参考

### 5.1 地理框架

```
魔都（主角主要活动地）：
- 金融中心、商业繁华
- 顶级财团总部所在地

帝都（政治中心）：
- 政策制定的地方
- 顶级豪门聚集地

深市（科技中心）：
- 科技企业发展迅速
- 创新氛围浓厚

各地分支：
- 主角势力逐渐向全国/全球扩张
```

### 5.2 历史沿革参考

- **十年前**：某个重大事件（商战/灾难/秘密实验），影响了现在格局
- **五年前**：主角离开/被陷害/失踪
- **现在**：主角回归/系统觉醒/能力觉醒，开始逆袭

## 六、使用说明

1. **选择子类型**：纯都市（无超凡）/ 都市超凡（有隐藏世界）/ 娱乐圈 / 医武 / 商战等
2. **设计能力体系**：根据子类型选择对应能力体系
3. **设计势力框架**：商业势力 或 隐秘势力，或两者结合
4. **设计金手指**：核心+隐藏，符合子类型
5. **选择独特亮点**：从 1.2 中选择至少3个，具体化
