# 历史题材 — 世界观参考模板

> 本文档为 worldview-agent 提供历史题材的世界观设计参考。加载后，按照本文档的框架生成世界观设定。

## 一、世界观框架参考

### 1.1 核心赛道公式
```
历史 + <核心冲突> + <势力博弈> + <特殊元素> + <能力体系> + <权力争霸>
```

示例：
- `历史 + 王朝更迭 + 忠臣奸臣博弈 + 穿越者 + 现代知识 + 辅佐明君`
- `历史 + 异族入侵 + 主战主和博弈 + 系统金手指 + 军事能力 + 保卫华夏`
- `历史 + 宫廷斗争 + 后宫前朝博弈 + 重生 + 预知未来 + 登上皇位`

### 1.2 独特亮点参考（至少选择3个）

- **穿越重生**：主角带着现代记忆/知识穿越到历史时期
- **系统金手指**：系统提供历史信息/技能/物品
- **改变历史**：主角有能力改变历史进程（风险：历史修正力）
- **双面间谍**：主角在多个势力之间周旋
- **隐世门派**：历史中隐藏的武林门派，介入朝堂
- **提前发明**：主角提前发明历史科技（火药/印刷术/蒸汽机等）
- **经济战争**：用现代经济知识搞垮敌国经济
- **文化输出**：用现代文化（诗词/小说/戏曲）征服朝堂/民间
- **军事改革**：用现代军事理论改革古代军队
- **医道救国**：主角精通医术，医治权贵/百姓，积累势力

## 三、势力设计参考

### 3.1 朝堂势力框架

```
皇帝（最高权力）：
- 忠臣派（主张XX）
- 奸臣派（主张XX）
- 中立派（墙头草）
- 外戚/宦官（特殊势力）

地方势力：
- 藩王（可能谋反）
- 地方豪强（掌控地方经济）
- 隐世家族（背后操控朝堂）

外国/异族势力：
- 北方游牧（军事威胁）
- 西域各国（贸易/联姻）
- 海外番国（未知势力）
```

### 3.2 隐藏势力参考

- **隐世门派**：武林中的隐世门派，介入朝堂斗争（第50章揭晓）
- **穿越者前辈**：已经有穿越者来过这个世界，留下了传承（第100章揭晓）
- **上古文明**：上古文明的存在，留下了遗迹/科技（第150章揭晓）

## 四、金手指设计参考

### 4.1 核心金手指

- **系统**：历史系统，可以查看历史人物信息/获得历史技能/兑换物品
- **现代知识**：主角携带现代知识（科技/军事/经济/文化）
- **武学传承**：获得隐世武学传承，武力值爆表
- **医术**：精通中医/西医，可以治病救人，积累人脉
- **预知未来**：知道历史走向，提前布局

### 4.2 隐藏金手指

- **双重身份**：主角表面上是小人物，实则隐藏身份（第30章揭晓）
- **前世记忆**：主角前世是历史学家/相关从业者，熟知历史细节（第50章揭晓）
- **神秘师父**：主角有一个神秘师父，是隐世高手/前朝遗老（第80章揭晓）

## 五、地理与历史参考

### 5.1 地理框架（以古代中国为例）

```
中原（核心区域）：
- 京城（政治中心）
- 江南（经济中心）
- 巴蜀（天府之国）
- 关中（四塞之地）

边疆：
- 北方草原（游牧民族）
- 西域（丝绸之路）
- 南方蛮荒（未开化地区）
- 东海/南洋（海外）
```

### 5.2 历史沿革参考

- **XX年前**：开国皇帝建立王朝
- **XX年前**：XXX事件，导致朝局变化
- **现在**：故事开始，王朝处于XX时期（盛世/中衰/末世）
- **未来**：历史走向（主角可能改变）

## 六、使用说明

1. **选择历史时期**：真实历史（唐宋元明清等）/ 架空历史
2. **设计核心冲突**：王朝更迭/异族入侵/宫廷斗争/农民起义等
3. **设计势力框架**：朝堂势力 + 地方势力 + 外国/异族势力 + 隐藏势力
4. **设计金手指**：与历史时期和能力体系匹配
5. **选择独特亮点**：从 1.2 中选择至少3个，具体化

## 七、质量检查

- [ ] 历史时期是否考据合理（服饰/礼仪/官制/军事等）？
- [ ] 核心冲突是否清晰？
- [ ] 势力框架是否合理？
- [ ] 金手指是否有趣且有限制（不能太bug）？
- [ ] 是否选择了至少3个独特亮点并具体化？
- [ ] 如果改变历史，是否有历史修正力的设定？
