# 悬疑题材 — 世界观参考模板

> 本文档为 worldview-agent 提供悬疑题材的世界观设计参考。加载后，按照本文档的框架生成世界观设定。

## 一、世界观框架参考

### 1.1 核心赛道公式
```
悬疑 + <核心谜团> + <正邪博弈> + <特殊元素> + <破案体系> + <真相揭晓>
```

示例：
- `悬疑 + 连环杀人案 + 警方与凶手博弈 + 心理侧写 + 多破案路线 + 擒获真凶`
- `悬疑 + 千年谜团 + 考古队博弈 + 超自然现象 + 科学解释 + 揭开真相`
- `悬疑 + 密室杀人 + 侦探与凶手博弈 + 不可能犯罪 + 逻辑推理 + 指出真凶`

### 1.2 独特亮点参考（至少选择3个）

- **连环杀人案**：一系列相互关联的杀人案件，凶手身份成谜
- **密室杀人**：不可能犯罪，密室中有人被杀，凶手如何作案成谜
- **心理侧写**：通过行为分析勾勒出凶手的心理特征
- **反转再反转**：真相多次反转，读者始终猜不到结局
- **多视角叙事**：侦探/凶手/受害者/警察等多视角叙事
- **超自然现象**：看似超自然的案件，最终用科学解释
- **历史谜团**：与历史事件相关的谜团
- **时间循环**：主人公陷入时间循环，必须破解谜团才能跳出
- **平行世界**：多个平行世界，案件相互关联
- **AI侦探**：AI 参与破案，与人类侦探合作/对抗

## 二、破案/能力体系参考

### 2.1 破案能力体系

| 能力类型 | 描述 |
|----------|------|
| 逻辑推理 | 通过线索推理出真相 |
| 心理侧写 | 通过行为分析勾勒凶手特征 |
| 法医鉴定 | 通过尸体/物证找出死因/凶手 |
| 痕迹检验 | 通过现场痕迹还原案发过程 |
| 大数据研判 | 通过大数据分析找出嫌疑人 |
| 审讯突破 | 通过审讯突破嫌疑人心理防线 |
| 跟踪监视 | 通过跟踪监视获取证据 |

### 2.2 角色能力参考

| 角色类型 | 能力 | 描述 |
|----------|------|------|
| 神探 | 逻辑推理+心理侧写 | 破案率极高，能看清人性 |
| 法医 | 法医鉴定 | 让尸体说话 |
| 痕检专家 | 痕迹检验 | 还原案发过程 |
| 技术员 | 大数据研判 | 用科技手段破案 |
| 老刑警 | 经验+直觉 | 办案经验丰富 |
| 犯罪心理专家 | 心理侧写 | 勾勒凶手心理画像 |
| 嫌疑人 | 反侦察能力 | 可能逃脱/可能冤枉 |

## 三、势力设计参考

### 3.1 正派势力框架

```
警方：
- 刑警队（主要破案力量）
- 法医中心（尸体/物证鉴定）
- 技术科（大数据/监控/通讯研判）
- 审讯科（审讯嫌疑人）

侦探/私家侦探：
- 独立侦探（主角）
- 侦探事务所
- 协助警方破案

法医/专家：
- 法医专家
- 心理专家
- 各类技术专家
```

### 3.2 反派势力框架

```
凶手/犯罪集团：
- 连环杀手（高智商，难以抓捕）
- 犯罪集团（有组织犯罪）
- 贪污腐败官员（利用权力阻碍破案）
- 恐怖组织（制造恐慌）

隐藏反派：
- 看似无辜的人实则是真凶（第X章揭晓）
- 警方内部有内鬼（第X章揭晓）
- 多起案件背后的操纵者（第X章揭晓）
```

### 3.3 中立势力

```
媒体：
- 报道案件
- 可能干扰破案
- 也可能提供线索

受害者家属：
- 渴望破案
- 可能私刑报复
- 也可能隐瞒线索

律师：
- 为嫌疑人辩护
- 可能利用法律漏洞脱罪
```

## 四、金手指设计参考

### 4.1 核心金手指

- **系统**：破案系统，可以扫描现场/分析线索/推理真相
- **重生记忆**：主角带着前世记忆重生，已知真凶身份
- **全息重现**：主角可以看到案件发生的全息影像
- **读心术**：主角可以读取他人心声（有限制）
- **超级大脑**：主角智商超高，推理能力逆天
- **法医系统**：主角精通法医知识，可以让尸体说话

### 4.2 隐藏金手指

- **双重身份**：主角表面上是侦探，实则是XX（第50章揭晓）
- **前世记忆**：主角前世是XXX，与本案有关（第80章揭晓）
- **神秘师父**：主角有一个神秘师父，是退休的神探（第30章揭晓）

## 五、案件设计参考

### 5.1 案件类型

- **杀人案**：故意杀人/过失杀人/激情杀人/预谋杀人
- **绑架案**：勒索绑架/复仇绑架/政治绑架
- **抢劫案**：入户抢劫/街头抢劫/银行抢劫
- **诈骗案**：电信诈骗/金融诈骗/婚姻诈骗
- **贪污案**：官员贪污/挪用公款
- **贩毒案**：毒品制造/运输/贩卖
- **走私案**：文物走私/毒品走私/人口走私

### 5.2 谜团设计

```
初级谜团（1-50章）：
- 表面谜团：看起来是A做的
- 第一次反转：其实是B做的
- 第二次反转：B是被人利用的
- 真相：幕后黑手是C

中级谜团（51-200章）：
- 多起案件相互关联
- 看似无关的案件，实则是一个大案的一部分
- 历史谜团与现实案件交织

终极谜团（201章-结局）：
- 所有案件的幕后黑手揭晓
- 意想不到的真凶
- 令人唏嘘的作案动机
```

## 六、使用说明

1. **选择核心谜团**：连环杀人案/密室杀人/历史谜团/超自然现象等
2. **设计正邪博弈**：警方与凶手/侦探与犯罪集团/多方势力博弈
3. **设计破案体系**：主角靠什么破案（推理/系统/法医/大数据等）
4. **设计势力框架**：正派 + 反派 + 中立势力 + 隐藏势力
5. **设计金手指**：与核心谜团和破案体系匹配
6. **设计案件**：初级谜团 + 中级谜团 + 终极谜团，层层递进
7. **选择独特亮点**：从 1.2 中选择至少3个，具体化

## 七、质量检查

- [ ] 核心谜团是否有趣且合理（不能太bug，不能无解）？
- [ ] 破案体系是否合理（不能太bug，要有推理过程）？
- [ ] 势力框架是否合理？
- [ ] 金手指是否有趣且有限制（不能开局直接知道真相）？
- [ ] 是否选择了至少3个独特亮点并具体化？
- [ ] 谜团设计是否有层次（初级→中级→终极）？
- [ ] 反转是否合理（不能为了反转而反转，要有铺垫）？
- [ ] 真相揭晓是否有冲击力（读者意想不到，但回头看发现铺垫充足）？
