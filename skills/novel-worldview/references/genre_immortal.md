# 仙侠/修仙题材 — 世界观参考模板

> 本文档为 worldview-agent 提供仙侠/修仙题材的世界观设计参考。加载后，按照本文档的框架生成世界观设定。

## 一、世界观框架参考

### 1.1 核心赛道公式
```
仙侠/修仙 + <核心冲突> + <势力博弈> + <特殊元素> + <多路线修炼> + <权力争霸>
```

示例：
- `修仙 + 仙魔大战 + 宗门博弈 + 上古传承 + 多路线修炼 + 仙界争霸`
- `修仙 + 末法时代 + 隐世宗门 + 现代修仙 + 科技修仙 + 重建仙界`

### 1.2 独特亮点参考（至少选择3个）

- **上古传承**：主角获得上古时期的修炼法门，与当世体系截然不同
- **多路线兼容**：不同修炼路线之间可以双修/多修，产生新能力
- **仙界架构**：完整的仙界层级设计（凡间→灵界→仙界→神界）
- **法宝体系**：法宝有成长路径（凡器→灵器→仙器→神器），可随主人成长
- **宗门势力**：宗门之间有联姻、敌对、附庸等复杂关系
- **末法时代**：灵气枯竭，主角如何逆袭
- **现代修仙**：修仙与现代社会结合（修仙公司、灵石货币化等）
- **重生修仙**：主角带着前世记忆重修，已知未来大势
- **废柴逆袭**：主角初始灵根被判定为废柴，实则隐藏神级灵根
- **仙魔双修**：同时修炼仙道和魔道，走前无古人的道路

## 三、势力设计参考

### 3.1 宗门势力框架

```
顶级宗门（3-5个）：
- 每个顶级宗门掌控一片区域
- 有化神期以上强者坐镇
- 拥有完整的大境界修炼传承

一流宗门（10-20个）：
- 附庸于顶级宗门，或保持中立
- 有元婴期强者坐镇
- 拥有至金丹期的传承

二流宗门（数十个）：
- 依附于一流宗门
- 有金丹期强者坐镇
- 拥有至筑基期的传承

三流宗门/家族（数百个）：
- 底层势力，相互争斗
- 有筑基期强者坐镇
- 只有练气期传承
```

### 3.2 仙界势力框架

```
仙界层级：
- 天庭（统治者）
- 佛界（中立势力）
- 妖界（中立偏敌对）
- 魔界（敌对势力）
- 散仙联盟（中立势力）
```

### 3.3 隐藏势力参考

- **上古传承势力**：上古时期留下的隐世势力，不参与当世争斗
- **仙界暗子**：仙界势力在凡间的暗子，监视凡间动态
- **域外势力**：来自其他世界的势力，图谋本土资源

## 四、金手指设计参考

### 4.1 核心金手指（参考）

- **上古传承**：获得上古大能的完整传承（功法+法宝+丹药+阵法）
- **混沌灵根**：天生混沌灵根，可修炼所有路线，且速度极快
- **炼丹/炼器天赋**：天生炼丹/炼器天赋，可炼制超越自身等级的丹药/法宝
- **时间法宝**：拥有加速时间的法宝（一天抵外界十天）
- **吞噬能力**：可以吞噬他人修为/法宝来提升自己
- **推演能力**：可以推演功法/丹方/阵法，创造属于自己的功法

### 4.2 隐藏金手指（参考）

- **前世记忆**：主角前世是仙界大能，转世重修（第50章揭晓）
- **神秘小塔**：体内有一个神秘小塔，可以存放活物/加速时间/防御攻击（第100章揭晓）
- **双生武魂**：主角拥有两个武魂，表面上是废武魂，实则第二个武魂是神级武魂（第30章揭晓）

### 4.3 成长型道具（参考）

- **本命法宝**：与主人共生的法宝，随主人修为提升而进化
- **神秘种子**：一枚神秘种子，可以成长为通天灵宝（需吸收天材地宝）
- **残图**：一张残图，集齐后可以找到上古秘境（共9张，分9个阶段获得）

## 五、地理与历史参考

### 5.1 地理框架

```
凡间界：
- 中州（核心区域，顶级宗门聚集地）
- 东域（修仙王朝，皇室修炼体系）
- 南荒（妖兽横行，蛮族部落）
- 西漠（佛修圣地，古寺林立）
- 北原（冰雪之地，体修聚集）

灵界：
- 更高一级的世界，凡间修士飞升之地

仙界：
- 天庭统治的三十三重天
```

### 5.2 历史沿革参考

- **上古大战**：上古时期仙魔大战，导致天地法则受损，修炼难度增加
- **末法时代**：灵气逐渐枯竭，修仙界逐渐没落
- **典籍失传**：上古功法失传，当世修炼体系不完整
- **仙路断绝**：凡间与仙界的通道被切断，飞升者皆有去无回

## 七、特殊设定参考

### 7.1 独特亮点（从 1.2 中选择至少3个，具体化）

示例（末法时代+现代修仙）：
- **灵气复苏**：全球灵气开始复苏，主角是最早感知到的人
- **修仙公司**：主角创立修仙公司，将修仙商业化（卖丹药、接任务）
- **直播修仙**：主角通过直播展示修仙，收获信仰之力提升修为

### 7.2 修炼资源参考

- **灵石**：修炼通用货币，蕴含纯淨灵气
- **丹药**：辅助修炼/突破瓶颈/疗伤
- **天材地宝**：稀有资源，可炼制丹药/法宝
- **功法**：修炼法诀，分天/地/玄/黄四级
- **法宝**：战斗/防御/辅助工具

### 7.3 法宝/神器参考

- **本命法宝**：与主人共生，最强法宝
- **攻击型法宝**：飞剑、宝塔、印章等
- **防御型法宝**：盾牌、铠甲、护罩等
- **辅助型法宝**：飞行法宝、储物法宝、探测法宝等
