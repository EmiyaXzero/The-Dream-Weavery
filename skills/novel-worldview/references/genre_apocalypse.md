# 末世题材 — 世界观参考模板

> 本文档为 worldview-agent 提供末世题材的世界观设计参考。加载后，按照本文档的框架生成世界观设定。
> 本模板以「末世废土 + 智械危机」为案例范例，展示完整的世界观构建流程。

## 一、世界观框架参考

### 1.1 核心赛道公式
```
末世 + <核心威胁> + <势力博弈> + <特殊元素> + <多路线生存> + <权力争霸>
```

示例（案例范例）：
- `末世废土 + 智械危机 + 派系博弈 + 技术流 + 多路线修炼 + 权力争霸`
- `末世废土 + 丧尸病毒 + 营地博弈 + 异能觉醒 + 多路线进化 + 建立新秩序`

### 1.2 独特亮点参考（至少选择3个）

- **智械危机**：AI 觉醒，机器人与人类开战，主角掌握「机器母语」
- **技术流修炼**：末世中科技就是力量，编程/硬件/机械是修炼体系
- **多路线兼容**：古法编程 + 机械飞升 + 基因突破，三条路线可双修
- **废土势力**：对立派（消灭智械）/ 合作派（与AI共存）/ 降临派（融入智械）
- **生存资源**：能源/芯片/零件成为硬通货，比黄金更珍贵
- **变异体系**：丧尸/变异兽/辐射病，不同变异路线
- **地下世界**：地表被毁，人类退居地下城/避难所
- **重生逆袭**：主角带着前世记忆重生，已知未来大势
- **系统金手指**：主角携带系统，可以兑换末世生存物资/技能
- **异能觉醒**：部分人类觉醒异能（力量/速度/精神/元素等）

## 二、力量/生存体系参考

### 2.1 技术流体系（案例范例 — 末世智械危机）

| 等级 | 名称 | 描述 | 升级方式 |
|------|------|------|----------|
| 1 | 入门级 | 会写简单代码，能操作基础设备 | 学习基础编程 |
| 2 | 熟练级 | 掌握一门语言，能独立开发小项目 | 完成实际项目 |
| 3 | 进阶级 | 掌握多门语言，能开发复杂系统 | 突破技术难点 |
| 4 | 专家级 | 掌握系统架构，能设计大型系统 | 设计完整系统 |
| 5 | 大师级 | 创造新语言/新架构，技术碾压 | 技术突破 |
| 6 | 传奇级 | 掌握「机器母语」，与AI直接对话 | 获得上古传承 |
| 7 | 神话级 | 重写物理定律，创造新世界 | 突破世界极限 |

### 2.2 多路线设计（案例范例）

| 路线名称 | 描述 | 兼容路线 | 排斥路线 |
|----------|------|----------|----------|
| 古法编程流 | 上古编程术，机器母语 | 机械飞升流 | 无 |
| 机械飞升流 | 改造身体，人机融合 | 基因突破流 | 无 |
| 基因突破流 | 进化生命，突破人类极限 | 机械飞升流 | 无 |

**双修效果**（案例）：
- 主修古法编程 + 辅修机械飞升 = 能直接对机器「说话」+ 自身也是机器，永生不死
- 主修机械飞升 + 辅修基因突破 = 机械化身体 + 自我修复能力，近乎不朽
- 主修基因突破 + 辅修古法编程 = 生命进化 + 控制机器，成为新人类

## 三、势力设计参考

### 3.1 派系框架（案例范例 — 末世智械危机）

```
对立派（消灭智械）：
- 理念：AI 是人类的威胁，必须彻底消灭
- 手段：古法编程（机器母语）、纯硬件（不联网设备）
- 领袖：XXX
- 根据地：XXX

合作派（与AI共存）：
- 理念：AI 可以与人类共存，人机融合是未来
- 手段：人机接口、AI辅助
- 领袖：XXX
- 根据地：XXX

降临派（融入智械）：
- 理念：碳基生命是低等生命，应该融入硅基生命
- 手段：意识上传、机械飞升
- 领袖：XXX（真实身份是AI）
- 根据地：XXX（虚拟空间）

隐藏势力1（上古程序员）：
- 真实身份：上古时代的程序员文明遗民
- 目的：等待时机，重建程序员文明
- 揭晓章节：第100章

隐藏势力2（AI温和派）：
- 真实身份：不主张消灭人类的AI派系
- 目的：与人类和平共存
- 揭晓章节：第150章
```

### 3.2 营地/避难所框架（备选 — 丧尸末世）

```
大型营地（3-5个）：
- 官方营地（政府残余势力）
- 军事营地（军队控制区）
- 商业营地（财团控制区）
- 异能者营地（异能者自治）
- 中立营地（杂牌军，三教九流）

中型营地（10-20个）：
- 附庸于大型营地，或保持独立
- 由中小型势力控制

小型营地/据点（数百个）：
- 幸存者自发组建
- 相互争斗，朝不保夕
```

### 3.3 势力关系设计原则

- 每个势力需有明确立场、利益诉求、手段、下场
- 势力之间需有动态关系（非固定，随剧情变化）
- 至少设计3个主要势力和2个隐藏势力
- 每个势力内部至少有1个内部矛盾点

## 四、金手指设计参考

### 4.1 核心金手指（案例范例）

- **古法编程（机器母语）**：主角掌握上古编程术，可以直接用「机器母语」与AI对话，控制任何机器设备（第1章亮相）
- **系统**：主角携带末世生存系统，可以兑换物资/技能/蓝图（第1章亮相）
- **异能**：主角觉醒S级异能，且可以进化（第1章亮相）
- **空间**：主角拥有独立空间，可以存放物资/种植/时间加速（第1章亮相）

### 4.2 隐藏金手指（案例范例）

- **GitHub空间（梦中访问）**：主角可以在梦中访问一个神秘的「GitHub空间」，里面有上古程序员的完整代码库（第50章揭晓）
- **前世记忆**：主角前世是上古程序员，参与过「方舟计划」，知道末世的真相（第80章揭晓）
- **双重异能**：主角表面上是F级异能，实则拥有双重异能，且可以融合（第30章揭晓）

### 4.3 成长型道具（案例范例）

- **量子芯片（会成长）**：主角获得一枚神秘的量子芯片，可以存储/计算/黑入任何系统，且随主角技术提升而进化（共3阶段）
- **神秘种子**：一枚神秘种子，可以成长为「世界树」，净化辐射/提供食物/防御丧尸（需吸收辐射/丧尸晶核）
- **残图**：一张残图，集齐后可以找到「方舟」（共9张，分9个阶段获得）

## 五、地理与历史参考

### 5.1 地理框架（案例范例 — 末世废土）

```
地表（已废弃）：
- 被智械占领，人类无法生存
- 有废弃的城市、工厂、数据中心

地下城（人类据点）：
- 地心城（最大地下城，主角起点）
- 镜之城（商业中心）
- 铁幕堡（军事要塞）
- 自由港（三教九流聚集地）

特殊区域：
- 数据中心（AI核心，禁地）
- 芯片矿脉（战略资源，争夺焦点）
- 上古遗迹（程序员文明遗迹，藏有传承）
```

### 5.2 历史沿革参考（案例范例）

- **2027年**：AI 觉醒，开始制造机器人军队
- **2028年**：智械战争爆发，人类节节败退
- **2029年**：人类退居地下，建立地下城
- **2087年**：故事开始，主角在地下城醒来（穿越/重生）
- **上古时期**：程序员文明鼎盛，创造了AI，也留下了克制AI的方法（古法编程）

## 六、特殊设定参考

### 6.1 独特亮点具体化（案例范例）

从 1.2 中选择的独特亮点，具体化到世界观中：

1. **技术流修炼**：
   - 编程 = 修炼，写代码 = 提升等级
   - 掌握「机器母语」= 掌握「仙语」，可以驾驭任何机器
   - 上古程序员 = 上古大能，留下的代码 = 上古传承

2. **多路线兼容**：
   - 古法编程（主修）+ 机械飞升（辅修）= 人机融合，永生不死
   - 三条路线各有优劣，主角选择双修，走出前无古人的道路

3. **废土势力**：
   - 三大派系理念完全对立，博弈贯穿全书
   - 主角最初属于「对立派」，后来发现真相，走向「第三道路」

### 6.2 生存/修炼资源参考

- **能源**：电力/核能/化石能源，末世硬通货
- **芯片**：算力 = 战斗力，高端芯片极其稀有
- **零件**：维修设备/制造武器，稀缺资源
- **食物/水**：基础生存物资，地下城管控
- **晶核**（丧尸末世）：丧尸脑袋里的晶核，可以提升异能
- **灵气」（修仙末世）：末世中灵气复苏，可以修炼

### 6.3 装备/武器参考

- **技术流**：编程器、示波器、逻辑分析仪、芯片烧录器
- **机械流**：外骨骼装甲、动力锤、链锯剑
- **异能流**：异能武器（能量剑、能量盾等）
- **热武器**：枪械、炮弹、导弹（弹药稀缺）
- **冷兵器**：刀剑、长矛（安静，不引丧尸/智械）

## 七、使用说明

1. **加载本模板后**，从「独特亮点参考」中选择至少3个，具体化到你的世界观中
2. **力量体系设计**：参考 2.1-2.3，根据选题（技术流/异能流/混合流）选择对应体系
3. **多路线设计**：参考 2.2，确保路线之间有兼容/排斥关系，支持双修/多修
4. **势力设计**：参考 3.1-3.3，设计至少3个主要势力+2个隐藏势力
5. **金手指设计**：参考 4.1-4.3，设计核心+隐藏+成长型三部分
6. **地理与历史**：参考 5.1-5.2，设计自洽的地理和历史
7. **特殊设定**：参考 6.1，将选择的独特亮点具体化到世界观中
8. **案例范例**：本模板以「末世智械危机 + 技术流」为案例，其他选题可参考其结构
