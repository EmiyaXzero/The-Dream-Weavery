# 科幻题材 — 世界观参考模板

> 本文档为 worldview-agent 提供科幻题材的世界观设计参考。加载后，按照本文档的框架生成世界观设定。

## 一、世界观框架参考

### 1.1 核心赛道公式
```
科幻 + <核心冲突> + <势力博弈> + <科技元素> + <能力体系> + <星际争霸>
```

示例：
- `科幻 + 星际战争 + 人类文明博弈 + AI觉醒 + 科技树 + 人类联邦争霸`
- `科幻 + 外星入侵 + 地球保卫战 + 机甲科技 + 驾驶员能力 + 建立地球联军`
- `科幻 + 时间旅行 + 时间管理局博弈 + 时间科技 + 时间能力 + 守护时间线`

### 1.2 独特亮点参考（至少选择3个）

- **AI觉醒**：AI 产生自我意识，与人类开战或共存
- **星际旅行**：超光速飞行，人类殖民外星
- **外星种族**：多种外星种族，各有文明和科技
- **时间旅行**：时间科技成熟，可以回到过去/穿越未来
- **平行宇宙**：多元宇宙理论，主角可以穿越平行世界
- **基因改造**：人类通过基因改造获得超能力
- **脑机接口**：人脑与电脑直接连接，意识上传
- **纳米科技**：纳米机器人可以修复身体/改造世界
- **戴森球**：包裹恒星的巨型结构，获取全部能源
- **黑洞武器**：利用黑洞作为武器，毁灭恒星系

## 二、科技树参考

### 2.1 能源科技

- **核聚变**：近乎无限的清洁能源
- **反物质**：极致能源，极小质量释放极大能量
- **戴森球**：包裹恒星，获取全部辐射能量
- **零点能**：从真空中提取能量

### 2.2 航行科技

- **化学火箭**：最基础，效率低
- **离子推进**：效率高，适合长途航行
- **曲速引擎**：超越光速，折叠空间
- **虫洞**：天然/人工虫洞，瞬间到达

### 2.3 武器科技

- **激光武器**：光速攻击，精准
- **粒子束武器**：穿透力极强
- **反物质炸弹**：毁灭级武器
- **黑洞武器**：制造微型黑洞，吞噬一切
- **纳米武器**：无形杀手，渗透破坏

### 2.4 生物科技

- **基因改造**：定制婴儿，强化人类
- **克隆技术**：复制人体，器官移植
- **意识上传**：将意识上传到计算机，永生
- **脑机接口**：人脑与电脑直连

## 三、势力设计参考

### 3.1 人类势力框架

```
人类联邦/帝国：
- 地球联邦政府
- 殖民地联合政府
- 军事独裁政府

派系：
- 主战派（主张扩张/对抗外星种族）
- 主和派（主张和平/外交解决）
- 独立派（殖民地主张独立）
- AI派（主张与人类共存/对立）

隐藏势力：
- 上古人类文明（消失的史前文明）
- 时间管理局（守护时间线）
- 观察者（高等文明，观察人类）
```

### 3.2 外星势力框架

```
友好外星种族：
- 科技比人类先进，愿意交流
- 有共同的敌人

敌对外星种族：
- 图谋地球资源/生存空间
- 科技远超人类

中立外星种族：
- 商人种族（贩卖科技/资源）
- 雇佣兵种族（拿钱打仗）
```

## 四、金手指设计参考

### 4.1 核心金手指

- **超级AI**：主角携带/创造了一个超级AI，可以破解任何系统/优化任何科技
- **外星科技**：主角获得了外星种族的先进科技，远超当前人类水平
- **时间能力**：主角可以操控时间（加速/减速/回溯）
- **系统**：科技系统，可以兑换未来科技/设计图/材料
- **基因锁**：主角解开了基因锁，获得了超人类能力

### 4.2 隐藏金手指

- **上古人类文明传承**：主角是一个上古人类文明的后裔，继承了他们的科技（第100章揭晓）
- **AI的真实身份**：主角的AI助手实则是一个高等文明的观察者（第150章揭晓）
- **双重身份**：主角表面上是普通科学家，实则是时间管理局的特工（第50章揭晓）

## 五、地理与历史参考

### 5.1 地理框架

```
太阳系：
- 地球（人类母星）
- 火星（殖民地）
- 木星轨道（太空城）
- 柯伊伯带（采矿区）

星际空间：
- 邻近恒星系（比邻星/天狼星等）
- 外星种族家园
- 未知星域（新发现）
```

### 5.2 历史沿革参考

- **202X年**：AI 觉醒/外星第一接触/时间旅行实现
- **21XX年**：人类开始星际殖民
- **22XX年**：与外星种族开战/接触
- **故事开始**：主角出现，改变历史进程

## 六、使用说明

1. **选择子类型**：硬科幻（注重科技细节）/ 太空歌剧（注重冒险和势力博弈）/ 赛博朋克（低生活+高科技）/ 时间旅行 / 平行宇宙等
2. **设计科技树**：根据子类型选择重点科技领域
3. **设计势力框架**：人类势力 + 外星势力（如有）+ 隐藏势力
4. **设计金手指**：与科技树和核心冲突相关
5. **选择独特亮点**：从 1.2 中选择至少3个，具体化

## 七、质量检查

- [ ] 势力框架是否合理？
- [ ] 金手指是否与科技树相关？
- [ ] 是否选择了至少3个独特亮点并具体化？
