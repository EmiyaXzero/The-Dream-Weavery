# 无限流题材 — 世界观参考模板

> 本文档为 worldview-agent 提供无限流题材的世界观设计参考。加载后，按照本文档的框架生成世界观设定。

## 一、世界观框架参考

### 1.1 核心赛道公式
```
无限流 + <核心冲突> + <主神空间博弈> + <副本世界> + <多能力体系> + <轮回者争霸>
```

示例：
- `无限流 + 主神空间内斗 + 轮回小队博弈 + 多元副本世界 + 多能力路线 + 成为主神`
- `无限流 + 系统BUG + 轮回者与主神博弈 + 原创+影视副本 + 多路线进化 + 摆脱控制`
- `无限流 + 跨世界观战力崩坏 + 多小队联盟/对抗 + 高难副本 + 基因锁体系 + 活到最后`

### 1.2 独特亮点参考（至少选择3个）

- **主神空间**：轮回者被主神强制送入副本世界完成任务
- **副本世界**：原创世界/影视/动漫/小说/游戏世界
- **多能力体系**：不同副本世界获得不同能力，可以组合
- **基因锁**：解开基因锁，获得超越人类的力量
- **轮回小队**：轮回者组成小队，相互协作/背叛
- **主神商店**：用奖励点数兑换技能/血统/装备
- **隐藏任务**：副本世界中的隐藏任务，奖励丰厚
- **跨世界观战力**：不同世界观的力量体系如何平衡
- **主神真相**：主神空间的真实目的（筛选强者/对抗域外威胁等）
- **轮回者对抗**：不同轮回小队在同一副本世界中对抗

## 二、力量/能力体系参考

### 2.1 基因锁体系（经典体系）

| 阶位 | 名称 | 描述 |
|------|------|------|
| 一阶 | 解开基因锁第一阶 | 爆发潜力，身体素质提升3倍 |
| 二阶 | 解开基因锁第二阶 | 控制身体每一部分，自愈能力 |
| 三阶 | 解开基因锁第三阶 | 预见未来（0.5秒），心灵之光觉醒 |
| 四阶 | 解开基因锁第四阶 | 改变现实，心灵之光实体化 |
| 五阶 | 圣人/仙人 | 超越主神，创造世界 |

### 2.2 血统体系

| 血统等级 | 名称 | 描述 |
|----------|------|------|
| F级 | 普通血统 | 无特殊能力 |
| E级 | 劣血统 | 微弱特殊能力 |
| D级 | 低血统 | 基础特殊能力 |
| C级 | 中血统 | 实用特殊能力 |
| B级 | 高血统 | 强大特殊能力 |

### 2.3 技能/装备体系

- **技能**：武学/魔法/异能/科技等，从副本世界获得
- **装备**：武器/防具/饰品等，从主神商店兑换或副本获得
- **道具**：消耗品/任务物品等
- **召唤兽**：从副本世界收服的伙伴

## 三、势力设计参考

### 3.1 主神空间框架

```
主神（最高存在）：
- 目的不明
- 掌控一切
- 不可违抗（表面）

轮回小队（主要势力）：
- 中洲队（主角所在队，平衡型）
- 恶魔队（激进型，不择手段）
- 天神队（精英型，配合默契）
- 北极队（科技型）
- 南炎队（异能型）
- 等等...

特殊势力：
- 主神空间管理员（隐藏）
- 超越者（已超越主神的存在）
- 域外威胁（主神空间的真正敌人）
```

### 3.2 隐藏势力参考

- **主神真相**：主神空间实则是XX（第100章揭晓）
- **超越者联盟**：已经超越主神的轮回者组成的秘密组织（第150章揭晓）
- **原初轮回者**：第一批轮回者，已经掌控主神空间（第200章揭晓）

## 四、金手指设计参考

### 4.1 核心金手指

- **主神碎片**：主角拥有主神碎片，可以绕过主神规则，私藏奖励
- **内力/真气**：从武侠副本中带出的内力，在主神空间非常稀有
- **合成台**：可以合成技能/血统/装备，突破主神商店的限制
- **预知能力**：可以预知副本剧情（有限制，不能全知全能）
- **强化路线**：选择了冷门但潜力巨大的强化路线

### 4.2 隐藏金手指

- **双重身份**：主角表面上是普通轮回者，实则是XX（第50章揭晓）
- **前世记忆**：主角前世是超越者，转世重修（第100章揭晓）
- **主神亲和**：主角实则是主神选中的「管理员候选」（第80章揭晓）

## 五、副本世界设计参考

### 5.1 副本类型

- **原创世界**：作者原创的副本世界
- **影视世界**：电影/电视剧世界（生化危机/侏罗纪公园/复仇者联盟等）
- **动漫世界**：日本动漫世界（火影/海贼王/龙珠等）
- **小说世界**：网络小说/经典小说世界
- **游戏世界**：电子游戏世界（英雄联盟/魔兽世界等）
- **历史世界**：真实历史世界（三国/隋唐等）

### 5.2 副本难度设计

```
D级难度：新手副本，死亡率低
C级难度：普通副本，有一定危险
B级难度：困难副本，死亡率中等
A级难度：极难副本，死亡率高
S级难度：地狱副本，死亡率极高
SS级难度：噩梦副本，几乎必死
```

## 六、使用说明

1. **选择核心冲突**：主神空间内斗/轮回者与主神博弈/跨小队对抗/域外威胁等
2. **设计主神空间规则**：奖励点数/支线剧情/复活机制/团队任务/个人任务等
3. **设计副本世界**：原创/影视/动漫/小说/游戏/历史，或混合
4. **设计力量体系**：基因锁/血统/技能/装备，如何平衡不同世界观的力量
5. **设计势力框架**：轮回小队 + 主神 + 隐藏势力
6. **设计金手指**：与核心冲突和力量体系匹配
7. **选择独特亮点**：从 1.2 中选择至少3个，具体化

## 七、质量检查

- [ ] 主神空间规则是否清晰（奖励/惩罚/复活等）？
- [ ] 副本世界是否有趣且多样？
- [ ] 力量体系是否平衡（不同世界观的力量如何换算）？
- [ ] 势力框架是否合理？
- [ ] 金手指是否有趣且有限制？
- [ ] 是否选择了至少3个独特亮点并具体化？
- [ ] 副本难度设计是否合理（有梯度）？
