# 游戏题材 — 世界观参考模板

> 本文档为 worldview-agent 提供游戏题材的世界观设计参考。加载后，按照本文档的框架生成世界观设定。

## 一、世界观框架参考

### 1.1 核心赛道公式
```
游戏 + <核心冲突> + <势力博弈> + <游戏系统> + <多职业体系> + <争霸全服>
```

示例：
- `游戏 + 帮派争霸 + 工作室博弈 + 全拟真游戏 + 多职业路线 + 称霸全服`
- `游戏 + 现实危机 + 游戏公会博弈 + 脑机接口游戏 + 现实游戏双线 + 拯救世界`
- `游戏 + 电竞职业赛 + 战队博弈 + MOBA/FPS游戏 + 多人竞技 + 世界冠军`

### 1.2 独特亮点参考（至少选择3个）

- **全拟真游戏**：VR/脑机接口，游戏世界与现实无异
- **游戏降临现实**：游戏中的能力/物品可以带到现实中
- **重生电竞**：主角带着前世记忆重生，已知比赛结果/版本更新
- **隐藏职业**：主角获得了隐藏职业，能力远超普通职业
- **游戏系统**：主角携带游戏系统，可以在现实中升级/学技能
- **全服第一**：主角目标是称霸全服，成为第一人
- **电竞职业赛**：主角参加职业电竞比赛，走上巅峰
- **游戏工作室**：主角创立游戏工作室，成为游戏界传奇
- **副本首杀**：主角团队拿下副本首杀，获得丰厚奖励
- **跨服战争**：不同服务器的玩家之间的战争

## 三、势力设计参考

### 3.1 游戏内势力框架

```
超级公会（3-5个）：
- 掌控主城
- 有众多高手
- 垄断高级副本/资源点

一流公会（10-20个）：
- 附庸于超级公会，或保持独立
- 有固定活动区域

中小型公会（数百个）：
- 玩家自发组建
- 相互争斗/合作

散人玩家：
- 不加入公会
- 部分高手散人
```

### 3.2 现实势力框架（如有现实线）

```
游戏公司：
- 开发/运营游戏
- 可能有权限操作游戏数据

电竞俱乐部：
- 职业战队
- 培养职业选手

游戏工作室：
- 打金/代练/带刷
- 形成产业

政府/协会：
- 监管游戏行业
- 举办官方赛事
```

### 3.3 隐藏势力参考

- **游戏BUG利用者**：发现并利用游戏BUG的玩家群体（第50章揭晓）
- **游戏公司内部人员**：在游戏中开小号的游戏公司员工（第80章揭晓）
- **游戏AI觉醒**：游戏中的NPC产生自我意识（第100章揭晓）

## 四、金手指设计参考

### 4.1 核心金手指

- **游戏系统**：主角携带游戏系统，可以在现实中升级/学技能/看属性面板
- **隐藏职业**：主角获得了隐藏职业，能力远超普通职业
- **副本攻略**：主角知道副本攻略/BOSS机制/隐藏任务
- **重生记忆**：主角带着前世记忆重生，已知版本更新/装备掉落/隐藏任务
- **全能大师**：主角可以 master 所有生活技能，制造极品装备/道具

### 4.2 隐藏金手指

- **双重身份**：主角在游戏中隐藏身份，实则是XX（第30章揭晓）
- **游戏设计师**：主角前世是游戏设计师，参与了这款游戏的设计（第50章揭晓）
- **NPC身份**：主角在游戏中的某个NPC实则是真实玩家（第100章揭晓）

## 五、游戏设定参考

### 5.1 游戏类型参考

- **MMORPG**：大型多人在线角色扮演游戏（如魔兽世界）
- **MOBA**：多人在线战术竞技游戏（如英雄联盟）
- **FPS**：第一人称射击游戏（如CS/守望先锋）
- **沙盒游戏**：开放世界游戏（如我的世界/方舟）
- **卡牌游戏**：卡牌对战游戏（如炉石传说）
- **音游**：音乐节奏游戏
- **全拟真VR游戏**：完全沉浸式VR游戏

### 5.2 游戏系统参考

- **等级系统**：角色等级，升级获得属性点和技能点
- **任务系统**：主线任务/支线任务/日常任务/隐藏任务
- **副本系统**：多人副本，需要组队挑战
- **PVP系统**：玩家对战，竞技场/战场/野外PK
- **交易系统**：拍卖行/摆摊/邮件交易
- **社交系统**：好友/公会/结婚/师徒
- **排行榜**：等级榜/战力榜/PK榜/副本竞速榜

## 六、使用说明

1. **选择游戏类型**：MMORPG/MOBA/FPS/全拟真VR/混合等
2. **设计核心冲突**：帮派争霸/电竞职业赛/游戏降临现实/现实危机等
3. **设计职业体系**：根据游戏类型设计职业/技能/装备体系
4. **设计势力框架**：游戏内公会 + 现实势力（如有）+ 隐藏势力
5. **设计金手指**：与游戏类型和核心冲突匹配
6. **选择独特亮点**：从 1.2 中选择至少3个，具体化

## 七、质量检查

- [ ] 游戏类型是否清晰？
- [ ] 职业/技能/装备体系是否合理？
- [ ] 游戏系统是否完整（等级/任务/副本/PVP/交易/社交等）？
