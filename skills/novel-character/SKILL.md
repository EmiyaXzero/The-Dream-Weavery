# Novel Character Skill

触发 character-agent 进行角色设计。支持按题材加载参考模板，生成结构化、有深度的人物设定。

## 触发词

角色、人物、人设、主角、配角、反派、人物设定、人物塑造、人物弧光、人物成长、人物关系、主角模板、反派模板、配角模板

## 行为

1. 加载 `agents/character-agent.md`
2. 根据题材类型加载 `skills/novel-character/references/character_templates.md` 参考模板
3. 根据世界观设定（`world_setting.json`）和用户需求设计角色
4. 输出完整角色设定文档（结构化JSON + 可读Markdown）
5. 触发下一环节（大纲规划）

## 输入文件

- 世界观设定：当前项目根目录下的 `world_setting.json` 或用户指定路径
- 创作需求：题材、风格、长度、平台、特殊要求

## 输出文件

- `./characters.json` — 结构化角色设定，保存在当前项目根目录
- `./characters.md` — 人类可读的角色文档，保存在当前项目根目录

## 人物塑造参考

### 主角型

- 核心性格（1-2个）+ 次要性格（1-2个）+ 性格缺陷（1个）
- 核心能力 + 辅助能力 + 成长路径
- 短期动机（1-50章）+ 中期动机（51-200章）+ 长期动机（201章以后）
- 金句（每20-50章至少1句）
- 人物弧光（8卷对应8个阶段的成长）

### 配角型

- 初始立场（敌对/傲慢/质疑）+ 转变契机 + 成长线
- 配角类型：傲娇型/憨厚型/机智型/冷酷型/妩媚型
- 要有独立人格，不能纯工具人
- 立场可以变化（从敌对到追随，或从追随到背叛）

### 反派型

- 动机（利益/权力/恐惧/理念冲突）+ 手段 + 下场
- 反派类型：权力狂/复仇者/理念对立者/唯利是图者/嫉妒者/幕后黑手
- 要有合理动机，不能纯恶
- 要有一定实力和智谋，不能太弱太蠢

### 神秘角色型

- 表面身份 + 真实身份（反转）+ 目的（多层次）
- 铺垫方式（3-5章埋细节）+ 揭晓方式（1章反转）
- 铺垫要自然，揭晓要有冲击力

## 质量标准

生成的角色设定必须包含：

1. **主角**：核心性格+能力+动机+金句+成长弧光
2. **配角**（至少2-3个）：初始立场+转变契机+成长线+独立人格
3. **反派**（至少1-2个）：动机+手段+下场+合理动机
4. **神秘角色**（可选）：表面身份+真实身份+铺垫+揭晓
5. **人物关系网络**：盟友/敌对/中立/暧昧/背叛关系
6. **人物弧光**：每个人物都要有成长/变化

## 角色行为限制（OOC检查清单）

**必须在角色设定中明确以下限制，避免创作时OOC：**

### 禁止事项清单

- [ ] 禁止使用"为了XX，为了所有人"等圣母句式
- [ ] 禁止角色突然变得崇高/无私（除非有铺垫）
- [ ] 禁止角色说不符合性格的话（如冷酷角色突然煽情）
- [ ] 禁止所有角色用同一种说话方式
- [ ] 禁止角色行为没有动机

### 角色专属语言风格

每个角色必须有独特的：
- 口头禅/常用词
- 说话长度（话多/话少）
- 情绪表达方式（外放/内敛）
- 价值观关键词

### 示例：林默的行为限制

```json
{
  "禁止事项": [
    "不说'为了所有人'这种空洞口号",
    "不做超出能力范围的承诺",
    "不主动帮助陌生人（除非有利益或情感驱动）",
    "不会突然原谅伤害过他的人"
  ],
  "语言风格": {
    "特点": "简洁、冷静、略带嘲讽",
    "常用句式": "短句，不废话",
    "情绪表达": "压抑，很少外露",
    "价值观": "实用主义，不做无意义的事"
  }
}
```

## 注意事项

- 必须参考 `references/character_templates.md`，避免人物套路化
- 每个重要角色都要有独立人格，不能纯工具人
- 人物行为要符合性格+立场+利益，不能OOC
- 配角的转变要有铺垫（3-5章）和转折（1章），不能太突兀
- 反派要有合理动机，不能纯恶
- 神秘角色的身份反转要有冲击力和合理解释
- **每个角色必须有禁止事项清单，防止OOC**
- **检查章节时，必须核对角色语言是否符合设定**
- 输出完成后，明确触发下一环节（大纲规划）
