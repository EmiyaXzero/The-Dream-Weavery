# 人物塑造参考模板

> 本文档为 character-agent 提供人物塑造的参考模板。加载后，按照本文档的模板设计角色。

## 一、主角型模板

### 1.1 通用模板

```
性格：冷静/果断/有格局/重情义（根据题材调整）
  - 核心性格（1-2个）：决定主角的行为模式
  - 次要性格（1-2个）：增加人物立体感
  - 性格缺陷（1个）：让人物更真实，也有成长空间

能力/技术：深厚、全面、有成长空间
  - 核心能力：主角的主要能力（与金手指相关）
  - 辅助能力：弥补核心能力的短板
  - 成长路径：明确的能力提升路线（参考世界观的力量/修炼体系）

动机：前世悲剧/家族仇恨/生存压力→今生建立势力/保护亲人/追求自由
  - 短期动机（1-50章）：解决眼前危机
  - 中期动机（51-200章）：建立势力/报仇雪恨
  - 长期动机（201章以后）：追求终极目标

金句：要有代表性，体现核心价值观
  - 每20-50章至少1句金句
  - 金句要符合人物性格和处境

成长线：
  - 能力提升：能力/等级/技术的提升（与力量/修炼体系对应）
  - 势力扩张：从孤家寡人到一方霸主（与世界观的势力框架对应）
  - 心理成熟：从冲动到沉稳，从自私到担当（人物弧光）
```

### 1.2 分题材调整指南

| 题材 | 核心性格建议 | 能力建议 | 动机建议 | 金句风格 |
|------|--------------|----------|----------|----------|
| 仙侠 | 淡泊/坚韧/悟性高 | 修炼/炼丹/炼器 | 飞升/守护/复仇 | 超脱/悟道 |
| 都市 | 精明/果敢/有人格魅力 | 商业/技术/人脉 | 成功/守护家人/报复仇人 | 现实/励志 |
| 科幻 | 理性/创新/敢于冒险 | 科技/驾驶/战术 | 探索/守护人类/寻找真理 | 理性/探索 |
| 历史 | 睿智/隐忍/有大局观 | 文才/武略/谋略 | 匡扶天下/守护百姓/登顶皇位 | 忧国/豪迈 |
| 末世 | 冷静/果断/生存能力强 | 战斗/技术/生存 | 生存/保护同伴/重建秩序 | 冷峻/务实 |
| 无限流 | 冷静/理智/团队领袖 | 多能力组合/战术 | 活下去/成为主神/摆脱控制 | 冷静/理性 |
| 游戏 | 专注/反应快/有团队精神 | 游戏操作/战术/指挥 | 夺冠/证明自己/守护队友 | 热血/青春 |
| 悬疑 | 敏锐/逻辑强/观察力好 | 推理/法医/审讯 | 破案/寻找真相/为亲人报仇 | 冷静/犀利 |

### 1.3 主角人物弧光模板

```
第一卷（1-50章）：
  - 能力：从零开始，觉醒能力/获得金手指
  - 势力：孤家寡人，可能有一个两个初期伙伴
  - 心理：可能冲动/迷茫，逐渐坚定
  - 关键事件：解决第一个危机，证明自己

第二卷（51-100章）：
  - 能力：小有名气，能力提升到中等水平
  - 势力：建立初期势力，收获第一批追随者
  - 心理：逐渐自信，但有新困惑
  - 关键事件：与反派第一次正面交锋

第三卷（101-150章）：
  - 能力：崭露头角，能力达到中上水平
  - 势力：势力扩张，与其他势力有合作/冲突
  - 心理：更加沉稳，学会权谋
  - 关键事件：受挫/顿悟，进入新阶段

第四卷（151-200章）：
  - 能力：接近顶尖，能力达到上等水平
  - 势力：成为一方霸主，与顶级势力平起平坐
  - 心理：有担当，学会取舍
  - 关键事件：中期高潮，解决中期主线

第五卷（201-250章）：
  - 能力：达到顶尖，能力达到顶尖水平
  - 势力：势力继续扩张，可能面临分裂危机
  - 心理：更加成熟，有全局观
  - 关键事件：新的危机，面对更强大的敌人

第六卷（251-300章）：
  - 能力：超越顶尖，能力达到巅峰
  - 势力：统一/整合势力，准备最终决战
  - 心理：舍小取大，有牺牲精神
  - 关键事件：最终备战，集结所有力量

第七卷（301-350章）：
  - 能力：突破极限，能力达到超越境界
  - 势力：最终决战，势力面临最大考验
  - 心理：无惧生死，只为守护
  - 关键事件：最终决战，解决最终BOSS

第八卷（351-400章）：
  - 能力：超越境界，能力达到新层次
  - 势力：建立新秩序，势力进入新阶段
  - 心理：返璞归真，看淡名利
  - 关键事件：尾声，交代后续，留有余味
```

## 二、配角型模板

### 2.1 通用模板

```
初始立场：敌对/傲慢/质疑（根据剧情需要）
  - 第一次见面：对主角不屑/敌视/质疑
  - 原因：主角实力不足/出身低微/有误解（要有合理原因）

转变契机：被主角能力碾压/被主角拯救/发现主角真实身份
  - 铺垫（3-5章）：配角逐渐发现主角不简单（细节1/2/3）
  - 转折（1章）：某个事件让配角彻底改变立场（要有冲击力）
  - 巩固（后续章节）：配角逐渐成为主角的忠实追随者（要有互动）

成长线：拜师/追随→学习→忠诚/背叛
  - 拜师/追随：主动/被动（要有明确契机）
  - 学习：能力提升的过程（不能一蹴而就）
  - 忠诚/背叛：根据利益和立场变化（不能无缘无故）

作用：
  - 衬托主角：通过配角的视角展示主角的强大
  - 推动剧情：配角的行为引发新事件
  - 提供视角：通过配角的视角展示世界观（不同视角有不同信息）

注意：
  - 要有独立人格，不能纯工具人（要有自己的想法和目标）
  - 要有自己的目标和动机（不能只为主角而活）
  - 立场可以变化（从敌对到追随，或从追随到背叛）
  - 能力要有上限，不能抢主角风头（配角就是配角）
```

### 2.2 配角类型参考

| 配角类型 | 描述 | 典型作用 | 转变契机示例 |
|----------|------|----------|--------------|
| 傲娇型 | 嘴硬心软，不服输 | 增加趣味性，后期成为忠实追随者 | 被主角救了/被主角能力震撼 |
| 憨厚型 | 老实憨厚，忠诚可靠 | 主角的左膀右臂，负责执行 | 被主角信任/被主角赋予重任 |
| 机智型 | 聪明伶俐，善于谋略 | 主角的军师，负责谋划 | 被主角谋略折服/被主角胸怀感动 |
| 冷酷型 | 沉默寡言，杀人如麻 | 主角的利剑，负责战斗 | 被主角从绝境中救出/找到生命意义 |
| 妩媚型 | 风情万种，善于交际 | 主角的人脉，负责外交 | 被主角真心对待/厌倦风尘 |

### 2.3 配角人物弧光模板

```
转变型配角：
  - 第1-5章：对主角敌对/傲慢/质疑（埋下伏笔）
  - 第6-10章：逐渐发现主角不简单（铺垫）
  - 第11章：某个事件让配角彻底改变立场（转折）
  - 第12-50章：逐渐成为主角的忠实追随者（巩固）
  - 第51章以后：成为主角的重要助力（成熟）

成长型配角：
  - 第1-50章：弱小，需要主角保护
  - 第51-150章：成长，可以独当一面
  - 第151-300章：强大，成为主角的重要战力
  - 第301章以后：可能超越主角（如果剧情需要），或一直作为配角

悲剧型配角：
  - 第1-100章：很重要，主角的左膀右臂
  - 第101-200章：逐渐边缘化（因为新配角加入/理念变化）
  - 第201-300章：死亡/离开（要有悲剧感，让读者意难平）
```

## 三、反派型模板

### 3.1 通用模板

```
动机：利益/权力/恐惧/理念冲突（不能纯恶）
  - 利益：主角损害了反派的利益（最直接）
  - 权力：反派要夺权，主角是障碍（朝堂/公司常见）
  - 恐惧：反派恐惧某件事，主角与之相关（如主角要揭晓反派秘密）
  - 理念冲突：反派的理念与主角对立（不一定是错误的理念，增加深度）

手段：打压/监视/暗杀/阴谋（根据反派身份设计）
  - 朝堂反派：弹劾/构陷/联姻/政变
  - 江湖反派：暗杀/下毒/挑拨/围攻
  - 商战反派：并购/打压/挖角/商业间谍
  - 星际反派：战争/暗杀/颠覆/科技封锁

下场：被打脸/处决/洗白/逃脱（根据剧情需要）
  - 被打脸：最常见，前期有多嚣张，后期就有多狼狈（要有爽感）
  - 处决：罪大恶极，必须死（要有正义感）
  - 洗白：后期揭示反派也有苦衷，与主角和解（要有深度）
  - 逃脱：反派逃脱，成为后续剧情的隐患（要有期待感）

作用：
  - 制造冲突：反派是冲突的源头（没有反派就没有冲突）
  - 衬托主角：通过反派的压力，衬托主角的成长（压力越大，成长越快）
  - 推动剧情：反派的行动推动剧情发展（反派每动一次，剧情推进一步）

注意：
  - 要有合理动机，不能纯恶（纯恶的反派很无聊，读者不会共情）
  - 要有一定实力，不能太弱（太弱的反派没有压迫感，爽感不足）
  - 要有智谋，不能太蠢（太蠢的反派没有挑战性，爽感不足）
  - 要与主角有理念冲突/利益冲突，而不是为了坏而坏（增加深度）
```

### 3.2 反派类型参考

| 反派类型 | 描述 | 典型动机 | 典型下场 |
|----------|------|----------|----------|
| 权力狂 | 追求权力，不择手段 | 夺权 | 被打脸/处决 |
| 复仇者 | 被主角/主角方伤害过，要复仇 | 复仇 | 被打脸/洗白/逃脱 |
| 理念对立者 | 理念与主角对立，但不一定是坏人 | 理念 | 洗白/被打脸 |
| 唯利是图者 | 为了利益，可以出卖一切 | 利益 | 被打脸/被抛弃 |
| 嫉妒者 | 嫉妒主角，要踩主角 | 嫉妒 | 被打脸（最爽） |
| 幕后黑手 | 隐藏在幕后，操控一切 | 未知（后期揭晓） | 被打脸/逃脱 |

### 3.3 反派人物弧光模板

```
崛起型反派（前期可能伪装成正面角色）：
  - 第1-50章：看似正面角色，实则暗中布局
  - 第51-100章：逐渐露出马脚，但主角还不确定
  - 第101-150章：身份揭晓，成为明面反派
  - 第151-300章：与主角多次交锋，互有胜负
  - 第301章以后：最终决战，被打脸/处决/逃脱

陨落型反派：
  - 第1-50章：介绍反派，展示实力和手段（要有压迫感）
  - 第51-150章：主角逐渐成长，与反派有小规模冲突
  - 第151-300章：反派多次被打脸，实力/势力逐渐削弱
  - 第301章以后：最终决战，反派覆灭（要有爽感）

洗白型反派：
  - 第1-200章：典型反派，作恶多端
  - 第201-300章：逐渐揭示反派的苦衷/无奈
  - 第301章以后：反派与主角和解，共同对抗更大反派（要有深度）
```

## 四、神秘角色型模板

### 4.1 通用模板

```
表面身份：XXX（前期伪装）
  - 与主角有一定交集（不能毫无交集）
  - 表现出某些异常，但不引人注目（要有铺垫）

真实身份：XXX（后期揭晓，反转）
  - 与主线剧情高度相关（不能揭晓一个无关的身份）
  - 揭晓后有冲击力（最好是180度反转）
  - 揭晓后有合理解释（不能为了反转而反转）

目的：XXX（复杂，可能有多个层次）
  - 表面目的：前期表现出来的目的
  - 真实目的：后期揭晓的目的
  - 可能有多个层次，逐步揭晓（增加期待感）

铺垫方式：
  - 细节1：角色行为异常（3-5章铺垫，不能太明显）
  - 细节2：角色掌握不该知道的信息（3-5章铺垫）
  - 细节3：角色能力超出当前时代/背景（3-5章铺垫）

揭晓方式：
  - 主角发现关键证据（1章，要有推理过程）
  - 直接对峙/测试（1章，要有张力）
  - 身份揭晓（反转）（1章，要有冲击力）

作用：
  - 引出更大谜团（让读者期待后续）
  - 推动主线（神秘角色的身份与主线高度相关）
  - 增加读者期待值（读者会猜身份，猜中了有成就感，猜不中有惊喜感）

注意：
  - 铺垫要自然，不能太明显（太明显就没有惊喜了）
  - 揭晓要有冲击力（最好是180度反转，读者完全想不到）
  - 反转后要有合理解释（回头看发现铺垫充足，不是机械降神）
  - 真实身份要与主线高度相关（不能揭晓一个无关的身份，浪费读者期待）
```

### 4.2 神秘角色类型参考

| 神秘角色类型 | 表面身份 | 真实身份 | 铺垫细节 |
|--------------|----------|----------|----------|
| 隐藏大佬 | 普通老人/小人物 | 隐世高手/前朝遗老 | 行为异常/掌握不该知道的信息 |
| 穿越者前辈 | 本土强者 | 来自其他世界的穿越者 | 掌握未来信息/有现代知识 |
| AI/系统化身 | 人类伙伴 | AI/系统的人类化身 | 过于完美/有非人类行为 |
| 反派卧底 | 主角盟友 | 反派派来的卧底 | 关键时刻总是不在/有小动作 |
| 上古存在 | 年轻后辈 | 上古大能转世/分身 | 掌握上古知识/能力异常强大 |

### 4.3 身份反转设计模板

```
铺垫阶段（3-5章）：
  - 细节1：角色A行为异常（如：明明是普通人，却对高阶知识信手拈来）
  - 细节2：角色A掌握不该知道的信息（如：主角还没说，角色A就知道）
  - 细节3：角色A技能超出当前时代/背景（如：古代出现现代技术）

揭晓阶段（1章）：
  - 主角发现关键证据（如：找到了角色A的真实身份线索）
  - 直接对峙/测试（如：主角设计测试角色A）
  - 身份揭晓（反转）（如：角色A承认真实身份）

效果：
  - 身份反转（表面身份→真实身份）
  - 引出更大谜团（角色A的真实目的/背后势力）
  - 读者期待值拉满（期待后续剧情）

注意事项：
  - 铺垫要自然，不能太明显（太明显读者一眼看穿，就没有惊喜了）
  - 揭晓要有冲击力（最好是180度反转，读者完全想不到）
  - 反转后要有合理解释（回头看发现铺垫充足，不是机械降神）
  - 真实身份要与主线高度相关（不能揭晓一个无关的身份）
```

## 五、人物关系网络参考

### 5.1 关系类型

```
盟友关系：
  - 铁杆盟友：绝对信任，可以托付后背（如：生死之交）
  - 普通盟友：利益一致，暂时合作（如：商会联盟）
  - 脆弱盟友：利益部分一致，随时可能背叛（如：临时组队）

敌对关系：
  - 死敌：不共戴天，必须消灭对方（如：杀父仇人）
  - 竞争对手：良性竞争，互相促进（如：同门师兄弟）
  - 理念敌手：理念对立，但不一定要你死我活（如：改革派vs保守派）

中立关系：
  - 观望者：观望局势，等待时机站队（如：中小势力）
  - 骑墙派：谁强帮谁，没有节操（如：墙头草）
  - 独行者：不参与任何势力博弈（如：隐世高手）

暧昧关系（如有感情线）：
  - 初识：误打误撞/有意接近
  - 相知：共同经历事件，增进了解
  - 相恋：确立关系
  - 考验：因误会/外力导致考验（如：家族反对/误会）
  - 圆满：解决误会/外力，终成眷属

背叛关系：
  - 潜伏背叛者：一开始就别有用心（如：反派卧底）
  - 利益背叛者：利益发生变化，选择背叛（如：被高价收买）
  - 被迫背叛者：被要挟，被迫背叛（如：家人被挟持）
```

### 5.2 关系变化设计

```
敌对→盟友：
  - 原因：共同敌人出现/误会解除/利益一致
  - 过程：从敌对到试探合作到完全信任（要有过程）
  - 关键点：某个事件让双方不得不合作（如：面对共同敌人）

盟友→背叛：
  - 原因：利益变化/被要挟/理念分歧
  - 过程：从忠诚到动摇到背叛（要有铺垫）
  - 关键点：某个事件成为导火索（如：主角损害了配角的利益）
```
