# 《废柴靠炼丹卷成仙尊》世界观设定

## 一、核心概念

> 穿越者林尘被测出三灵根废柴资质，觉醒了【炼丹模拟器】系统，可以在脑海中无限模拟炼丹，零成本掌握丹方。别人炼丹费材料，他无本万利。从被赶出家族到成为修仙界丹尊，一路用丹药打脸逆袭。

### 独特亮点
1. **炼丹模拟器金手指**：零成本无限试错，模拟即可掌握丹方
2. **丹药经济体系**：用丹药垄断市场，操控修仙界经济命脉
3. **废柴逆袭打脸**：三灵根被看不起？用炼丹天赋碾压天才

## 二、力量/修炼体系

### 修仙九境

| 大境界 | 小境界 | 描述 |
|--------|--------|------|
| 炼气期 | 1-9层 | 引气入体，温养经脉 |
| 筑基期 | 初期/中期/后期/圆满 | 灵气液化，筑基成台 |
| 金丹期 | 初期/中期/后期/圆满 | 凝丹成金，寿元五百 |
| 元婴期 | 初期/中期/后期/圆满 | 元婴破丹，神识外放 |
| 化神期 | 初期/中期/后期/圆满 | 元神不灭，沟通天地 |

### 修炼路线

| 路线 | 描述 | 兼容 | 排斥 |
|------|------|------|------|
| 丹修 | 以炼丹入道，靠丹药提升修为 | 医修、法修 | 体修 |
| 剑修 | 以剑入道，攻击极强 | 法修 | 魂修 |
| 法修 | 法术攻击，范围伤害 | 符修、丹修 | 体修 |
| 体修 | 炼体成圣 | 武修 | 法修、丹修 |
| 符修 | 符箓攻击 | 阵修 | 无 |

### 升级方式
- 吸收天地灵气（常规方式）
- **服用丹药（主角核心方式）**
- 炼丹时悟道突破境界
- 生死之间战斗突破

> **主角路线**：走丹修路线，灵根差但丹药管够，靠高品质丹药快速升级。

## 四、历史背景

**时代**：末法时代中期

上古仙魔大战后，天地灵气衰退，大量上古丹方失传，炼丹术大幅倒退。当世炼丹师只能炼制基础丹药，高阶丹药几乎绝迹。正因如此，炼丹师在修仙界的地位极高——但也正因没落，真正的炼丹大师凤毛麟角。

## 六、金手指系统

### 【炼丹模拟器】核心金手指

主角穿越觉醒的逆天金手指——可在脑海中进行炼丹模拟，零成本无限试错。模拟成功后自动掌握丹方，现实中炼制100%成功。

| 阶段 | 解锁等级 | 能力 |
|------|----------|------|
| 第一阶段 | 炼气期 | 模拟黄级丹药 |
| 第二阶段 | 筑基期 | 模拟玄级丹药 |
| 第三阶段 | 金丹期 | 模拟地级丹药 |
| 第四阶段 | 元婴期 | 模拟天级丹药 |
| 第五阶段 | 化神期 | 模拟道级丹药 |

**隐藏设定**：模拟器实际融合了上古丹圣残魂，化神期时觉醒，揭示真正来历。

### 成长型道具

1. **乾坤鼎**：地摊淘到的破旧丹鼎，实为上古神器残片，随主角成长而进化
2. **药神秘典**：上古丹圣炼丹笔记残卷，记录失传丹方
